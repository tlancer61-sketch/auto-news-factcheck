# 从产品目的推到判断与处理路线

第一性原理用于构建可证伪的问题，不代替事实采集、工程鉴定或法律适用。对安全问题默认执行；其他事件按合同交付、信息真实性等实际目的调整。

## 六步推导

1. 产品目的：产品承担什么功能、服务谁、受保护的利益是什么？汽车制动争议先问在需减速或停车时，驾驶者的制动输入能否按要求可靠传递，而非品牌口碑或材料贵贱。
2. 失效与伤害路径：输入/操作 → 承载与连接 → 控制与执行 → 整车效果 → 人身财产后果。分别标已观察失效、假设机制、尚未发生或未证实的损害；分析其他保护措施是否实际可用，不以存在备用功能自动否定风险。
3. 使用边界：区分正常使用、可合理预见的紧急操作或误用、与产品用途明显无关的破坏。每项给出认定所需证据。紧急制动不能只因少见就排除在设计讨论外；也不能宣称任何无限外力下都应不坏。标准符合性试验、设计边界试验、缺陷复现的目的不同。非标不自动无效，试验断裂也不自动证明日常必坏。
4. 权利义务：按实际问题选择产品质量与缺陷召回、消费者安全/知情/真实答复、车辆准入/强制标准、交通事故及损害赔偿、三包与合同等规则。没有事故不硬套事故责任，没有退换事实不硬套三包。逐项写法域、事件时版本、条款、触发前提、义务主体和未证明的要件；引用法规原文实时核验，不将本指南当法条库。
5. 决定性证据：对设计、制造、安装、使用方式、测试偏差等竞争解释，写它预期观察到什么、什么能否定它、谁掌握材料、目前缺什么。区分建议披露数据与法定举证责任；不能自行规定司法举证责任倒置，不能要求公开商业秘密或个人数据。主管机关可依法取得完整材料，对公众说明可使用必要摘要。
6. 给出判断与路径：事实判断、工程风险判断、法定义务判断、处理建议、现实走向预测分别标注。每个判断写前提、证据、反证、把握度理由和哪些新信息会改变结论。可以原因未定但调查义务已经触发；不能因等待原因就把应采取的保护推迟。

## 条件处理矩阵

- 可信安全线索、原因未定：依法调查和报告，保全样件/原始数据；建议主管机关组织可复核复现、覆盖量产一致性，企业向用户提供可执行的临时安排及更新节点。区分已达到法定触发条件与研究者的审慎建议，不直接把线索等同违法或全系停驶命令。
- 确认存在法定缺陷：按适用法履行停产停售、备案/召回、告知、费用承担等义务，并明确车型/批次/VIN范围；以法规实际条款为准，不把免费服务命名当免责。
- 独立证据证明测试超出合理使用且不能反映量产风险：公开必要方法与可复核依据，纠正不实传播；仍检查是否存在未被排除的失效路径，不以质疑测试方动机替代技术解释。
- 混合原因或批次问题：按影响范围和各主体行为分别处理，不能把制造与使用原因硬作二选一。
- 改进后闭环：验证措施是否消除原失效路径、量产件是否一致、用户触达与完成率、未完成者安排和后续监测。公关回应或开始更换不是技术闭环。

## 必须回答的结论句

“当前证据支持……；仍不能确认……。基于……义务/风险，我判断现在应……。如果核查证实A，则应……；如果证实B，则应……；出现……新证据时应修正判断。”

“应该怎样处理”是有依据的规范判断。“预计企业/监管会怎样做”是预测，只有存在公开行动、制度激励等依据时给条件情景，不编概率、不预测必然结局。
