# 法规与官方声明分析

## 法律法规

先识别交通事故责任、产品质量/缺陷召回、消费合同/交付、广告宣传、个人信息等实际相关领域，不堆法条。

到国家法律法规数据库、中国政府网、全国人大及主管部门官网核读原文。关键法律判断再找权威释义、适用解释或公开案例交叉验证；案例保留案号、法院、日期及事实差异，不把个案裁判推广成统一规则。三源不足如实标注。

记录规范全名、机关、条款、法域、层级（法律/法规/规章/标准/征求意见稿）、公布/施行/修订/废止日期、事件时是否生效及适用前提。征求意见稿不当现行法，推荐性标准不自动当强制义务；符合某标准不自动排除全部缺陷和责任。

按“规则要求 → 当前证据 → 缺少要件 → 有限结论”分析。区分事故责任、民事责任、行政责任、刑事责任和舆论评价；受理、立案、调查、鉴定、处罚、裁判是不同阶段。未找到原文则说明未能核验。涉及未公开合同、鉴定或专业争议时给条件分析，不擅作司法结论。

## 官方说明的三层阅读

先分类：车企、经销商、政府部门、警方、监管、法院各是什么主体；“官方”不意味着相同权限或独立性。保存原文链接和版本，仅摘必要短句，遵守来源引用限制。声明发布可确认，声明内的因果、数据仍需核查。

### 官方角度

提取明确承认/否认、依据、调查主体和对象、完成/未完成事项、处理承诺、时间表和责任主体。核查回应是否覆盖原始质疑；把宣称修复、承诺赔付和可验证完成记录分开。

### 社会与消费者角度

对照安全、知情权、维修成本、交付承诺、补偿、调查透明度等问题，分已答、部分答、未答。区分可检索的公众诉求与分析者提出的问题。热评/热搜不代表全体消费者，无系统抽样不宣称“公众普遍认为”。提出双方可验证的后续问题。

### 语言文法角度

逐句看主语、谓语、宾语、否定范围、量词、时间词、条件词、情态词、被动句、省略施事及指代对象。按“原句短摘 → 字面含义 → 能支持什么 → 不能推出什么 → 待补信息”输出。

- “截至目前/暂未发现”：受时间、方法限制，不等于永远不存在。
- “本次送检车辆/部分批次”：对象有限，不等于全系全部年份。
- “未发现设计缺陷”：不能排除制造缺陷、个车故障、维修问题等。
- “符合标准”：查标准版本、检测对象和范围，不自动证明全场景安全。
- “积极配合调查”：行动表态，不等于调查完成或免责。
- “网传内容不实”：界定具体反驳对象，不扩大到整个事件。
- “将/拟/计划”：承诺或预测，不等于兑现。

可指出措辞效果和合理读法，但“回避责任”“故意误导”“心虚”等动机指控需要额外证据。语言形式无法测谎，缺少回应不等于承认。歧义保留歧义，不替发布方补全意图。

## 完全虚构示例

甲品牌称“截至目前，在本次送检车辆中未发现制动系统设计缺陷”；车主称制动失灵，三家媒体转述声明。

可说：品牌陈述了限定范围的检测结论，报道同源；故障原因待独立核查。不可说全系无故障、车主造谣、品牌免责。需要原始检测报告、方法与对象、车辆日志、维修/事故记录、相关部门结论。法律责任另按法域、时间与具体证据分析。
